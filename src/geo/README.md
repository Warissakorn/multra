Desktop-only Qt-free PROJ transforms between WGS84, Web Mercator and one fixed WGS84 UTM CRS. Project coordinates use a translated/rotated local origin. XYZ tile math lives in tile_grid. Core/eval and headless persistence do not import this module. See [map contract](../../docs/reference/MAP_BACKGROUND.md).

`projection_data` locates the bundled database independently of content-directory overrides.
