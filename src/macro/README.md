Static assignment for the Macro level (S2, M10.1; [contract](../../docs/reference/MACRO_NETWORK.md), [as implemented](../../docs/reference/MACRO_NETWORK_IMPLEMENTED.md)). Pure and Qt-free: it imports nothing outside this folder, reads no clock and draws no random number.

`graph.*` holds the Macro graph as plain values (links, connectors and centroid arcs, link types); `settings.hpp` holds `MacroSettings` alone, so the authoring definition need not include the graph; `compileMacroNetwork` in `src/model/demand/macro_compile.*` fills it from the drawn network (D273). `assign.*` is the assignment (D274): BPR `macroTime`, `shortestTree` (Dijkstra, ties to the lower link index), `allOrNothing`, and `assignMacro`, a multi-class Frank–Wolfe on the shared pcu load with an exact line search, the relative gap of §7, a convergence record per iteration and an observer that can cancel between iterations (D277). One study period is run by `src/project/macro_run.*`; outputs are `src/project/macro_output.*`. MA15, the textbook benchmark, reproduces Sheffi (1985) Table 5.4 (D294, `tests/macro_benchmark_tests.cpp`). That is one row of the M10 gate, not validation: the not-validated marker stays until M6.
